# 高校列表入校动画回归

2026-09-06，独立 Playwright CLI Chrome 会话，本地 `http://localhost:3000`。桌面 1047×717、手机布局 390×844。仅执行浏览器检查并写本记录与截图，未修改运行代码。

## 入校时序与视角

在搜索“大学”的全国根页点击高校列表，检查根 URL、入校状态、真实 Three.js camera/controls target 与最终路由：

| 学校 | 点击后 250 ms | 从 click 返回到校园路由 | 最终路由 |
|---|---|---|---|
| 北京大学 | 仍在 `/?q=大学`，显示“正在前往 北京大学”，camera 从 `[0,75,63]` 移向约 `[11.27,35.43,23.13]` | 约 2.55 s | `/university/10001/campus/main?q=大学` |
| 贵州大学 | 仍在根 URL，显示“正在前往 贵州大学”，camera 从北京视点移向约 `[6.51,15.90,20.62]` | 约 2.03 s | `/university/10657/campus/main?q=大学` |

两次均实际飞行后才入校；返回全国地图时 camera 和 target 与入校前保存的最后地图视点完全相同，搜索值“大学”保留。该时间是本地开发会话采样，不是网络加载性能保证。

## 取消与快速操作

| 检查 | 结果 |
|---|---|
| 点击取消按钮 | PASS，等待 3.5 s 后仍在根 URL，进入状态已消失 |
| Escape 取消 | PASS，等待 3.5 s 后仍在根 URL，无延迟跳转 |
| 空白地图拖动取消 | PASS，起点 `(440,150)` 及周围区域经 elementFromPoint 确认为 CANVAS；拖动后等待 3.5 s 仍在根 URL，无进入状态 |
| 取消后再选同校 | PASS，重新选择北京大学成功进入对应校园 |
| 连续改选两所学校 | PASS，先贵州大学后北京大学；每 10 ms 采样只观察到 `/`→北京校园，随后等待 2.8 s 未跳往贵州 |
| 入校后立即返回 | PASS，连续 3 次返回全国地图分别耗时约 172/159/134 ms，camera/target 和搜索值均保留 |
| 快速返回连接错误 | 未复现 `connect null.addEventListener`，三次返回均能正常读取重建后的地图相机与控制器 |

首次按固定坐标尝试拖动时实际命中了地图学校标签，触发了标签选择；这两次未计入空白地图取消结论。正式取消验证使用命中检查后确认的 Canvas 起点。

## 手机和减少动态效果

手机 390×844、页面 scale=1，选择北京大学后约 200 ms 仍在根页并显示“正在前往 北京大学”，面板已收起。camera 从 `[2.49,16.07,27.39]` 移至约 `[11.18,15.70,12.75]`；随后完成入校，展开校园信息并返回高校列表成功。

使用 Playwright `emulateMedia({ reducedMotion: 'reduce' })`，确认媒体查询为 true；点击贵州大学约 72.5 ms 后进入对应校园，没有飞行状态条。

本会话控制台日志没有 ERROR，边界操作收集到的 pageerror / console error 数组为空；只有已知 Three.Clock 弃用警告及正常释放时的 WebGL Context Lost 日志。重置筛选取消飞行的最终补丁由站点负责者另行检查，本记录不将其计为已测覆盖。
