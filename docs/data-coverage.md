## 可复现流程与验证

- `python3 scripts/prepare-data.py` 读取版本化源数据和校区选择，不下载、不修改全国底图；保留补充简介、来源及稳定ID。
- `python3 scripts/fetch-campuses.py` 复用同一OSM源的缓存，候选身份变更时重新下载；原始和派生数据分离。
- `node scripts/build-campuses.mjs` 全量生成；`--ids=10358,10561` 只重建指定学校并保留其他manifest条目。生成不会提升核验标记。
- `node scripts/build-campuses.mjs --self-test` 已通过：跨界线段、内洞保留、未闭合环拒绝。112份资产的学校名称与OSM源ID映射已逐项检查。

## 鸟瞰闪烁修复与几何减量

已移除建筑挤出体重复的屋顶顶盖，独立屋顶位于原挤出高度，侧墙、底面、校园轮廓和高度数据保持不变。112份GLB均通过哈希、点击面区间、POI源ID映射及无重复水平顶盖检查。

共移除93124个重复三角形（12.05%），模型总大小由79983752降至71043496字节，减少11.18%。清华与上海大学新模型经站点负责者截图确认，大面积屋顶三角噪点消失；完整逐校检查保存在data/geometry-flicker-audit.json。该技术修复不提升真实布局或精细建筑的验收状态。
