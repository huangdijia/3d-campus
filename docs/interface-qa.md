# 界面与集成回归记录

验证日期：2026-09-06。浏览器验证针对本地开发服务；构建结果单独记录，不把开发预览作为全量校园验收。

## 当前流程

- 高校列表点击一次进入该校校园；已有校园的旧 `/university/:id` 地址自动归一到校园地址。
- 校园侧栏显示校徽、可展开的学校介绍及官网入口；返回直接到高校列表。
- 筛选、建筑、搜索与游览模式同步 URL；前进、后退、刷新及分享可恢复对应内容。
- 手机默认显示全屏地图和底部信息条，支持点击/上滑展开面板、下拉/点击收起；选择学校、建筑与模式后自动收起。

## 性能与闪烁

- 全国地图同一桌面初始视角：绘制调用 133 → 5；三角形 73,964 → 42,290；GPU 几何对象 133 → 5。
- 全国地图在资源与相机稳定后，3 秒内实际新增渲染帧数为 0；鼠标操作与镜头飞行仍触发绘制。
- 校园模型移除重复顶盖：112 个模型共减少 93,124 个三角形（12.05%）；79,983,752 → 71,043,496 字节，减少 8,940,256 字节（11.18%）。
- 鸟瞰使用对数深度缓冲、动态裁剪范围及按需绘制；物理运行时与碰撞网格仅在进入漫游时加载。独立实测见校园 QA。

帧率数据受设备、前台状态和开发构建影响，不能当作所有手机性能保证。Playwright WebKit 覆盖也不等同于所有实体 iPhone/Safari 验收。

## 构建与发布限制

TypeScript 与本次代码范围（`app scripts tests`）Oxlint 通过，生产构建通过。仓库全量 Oxlint 仍有脚手架自带组件的既存问题，不宣称全仓 lint 通过。Three.js / Rapier 在开发运行时有弃用提示，构建存在大包提示；漫游代码已拆为按需块。

技术资源校验：115 所名录、112 个模型、7,728 个来源命名 POI，技术错误为 0。严格发布检查仍失败：精细地标、官方 POI、布局和路线等逐校验收未完成，且全国边界未完成标准地图核验。当前 0 所通过完整校园验收，保持开发预览，不公开发布为首期完成版本。
